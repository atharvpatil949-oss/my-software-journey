## Projects

### 🚀 Interactive Mark Tracker & Analyzer
A robust C++ command-line tool that records, categorizes, and analyzes student grades.

* **Robust Input Handling:** Actively prevents system crashes by validating user inputs against decimal points or character errors.
* **Dynamic Decision Logic:** Automatically maps numerical marks to corresponding grades ($A+$, $A$, $B$, etc.) using conditional structures.
* **Statistical Analysis:** Processes data streams to instantly calculate class averages and identify the highest score (Topper).

- Language: C++
